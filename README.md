# UniPreT

**UniPreT** stands for Unix Preprocessing for Text. It is a framework consisting of POSIX-compliant scripts for preprocessing of text, which is usually one of the first steps in an NLP pipeline.

# Modules

The modules currently present in UniPreT are:

- lowercase
- uppercase
- strip-punctuation
- tokenize
- ngrams
- frequency

Use the flag `--help` while running any of the scripts to get help regarding the usage and the flags.
